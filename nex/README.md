# Nex Browser 0.3

Приватный мобильный браузер: минималистичный интерфейс, блокировка рекламы до загрузки,
никаких аккаунтов и телеметрии. Целевая платформа — **Android, Kotlin + Jetpack Compose + GeckoView**.

В репозитории три связанных артефакта:

| Что | Где | Зачем |
|---|---|---|
| Интерактивный прототип | `nex/index.html` | кликабельный интерфейс, все экраны |
| Устанавливаемая PWA | `nex/manifest.json`, `nex/sw.js`, `nex/icons/` | «Установить приложение» на Android, офлайн-запуск |
| Android-проект | `android/` | Kotlin, GeckoView, сборка APK |
| Сборка APK | `.github/workflows/android.yml` | GitHub Actions собирает `app-debug.apk` |

## Открыть прототип

```bash
# из корня репозитория
python3 -m http.server 8080
# → http://localhost:8080/nex/
```

Локальный сервер нужен для service worker и установки как приложения: по `file://`
манифест и офлайн-кэш не работают.

## Что нового в 0.3

**Дизайн**

- три темы: светлая, `dim`, тёмная — переключатель в настройках и чип на главном экране;
- единая система SVG-иконок вместо эмодзи и текстовых символов;
- нижняя панель со стеклянным фоном, который включается при прокрутке;
- пружинные нажатия, аккуратные переходы между экранами, читаемая типографика;
- переработаны состояния: пустые списки, активные вкладки, приватные вкладки (пунктирная рамка).

**Функции**

| Функция | Где | Что делает |
|---|---|---|
| Группы вкладок | Вкладки | «Чтение» и «Остальные», фильтр по группе и по приватным |
| Приватные вкладки | Вкладки, меню | отдельная сессия, помечена пунктиром и иконкой |
| Find-in-page | Статья, меню | подсветка совпадений, счётчик, автоскролл к первому |
| Split view | Статья, меню | две страницы на одном экране |
| История | Виджет, меню | группировка по дням, поиск, удаление записи и дня, очистка целиком |
| Закладки | Виджет, меню | сохранение из статьи, сетка, экспорт в HTML |
| Настройки | Меню | тема, поисковый движок, кегль, приватность, движок |
| Читалка | Статья | кегль А−/А/А+, интерлиньяж, только текст |
| Подтверждения | История, вкладки | диалог вместо мгновенного необратимого действия |

**PWA**

- `manifest.json`: standalone-запуск, иконки `any` и `maskable`, три shortcut-а;
- `sw.js`: cache-first для локальных файлов, навигация с офлайн-фолбэком;
- `#stealth`, `#history`, `#shield`, `#settings` — прямые ссылки на экраны.

## Про APK

В песочнице, где писался этот прототип, нет JDK и Android SDK, а `dl.google.com` и
`maven.mozilla.org` закрыты — скомпилировать APK там нечем. Поэтому APK собирается в CI:

1. **Actions → Android APK → Run workflow**;
2. артефакт `nex-browser-debug-apk` содержит `app-debug.apk`;
3. workflow сам подставляет актуальную версию GeckoView 128.x из `maven.mozilla.org`.

Подробности и локальная сборка — в [`../android/README.md`](../android/README.md).

## Структура

```
nex/
├── index.html          # прототип: разметка, стили, логика
├── manifest.json       # PWA
├── sw.js               # офлайн-оболочка
├── icons/              # иконки 192/512 + maskable
└── assets/             # изображение статьи
android/
├── app/src/main/java/app/nex/browser/
│   ├── MainActivity.kt # GeckoRuntime, приватные настройки
│   ├── NexApp.kt       # экраны на Compose
│   ├── NexEngine.kt    # сессии, поиск, чистка utm
│   └── NexTheme.kt     # три темы, токены
├── gradle/wrapper/     # Gradle 8.9
└── build.gradle.kts
```
