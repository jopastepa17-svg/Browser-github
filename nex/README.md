# Nex Browser — прототип интерфейса v0.2

Кликабельный прототип мобильного браузера. Один файл, без зависимостей и сборки.

**Открыть:** `nex/index.html`

## Решения, зафиксированные до разработки

| Аспект | Решение | Почему |
|---|---|---|
| Платформа | Android, Kotlin, Jetpack Compose | GeckoView существует только под Android; один рынок — быстрый цикл |
| Движок | GeckoView (Gecko) + WebExtensions | независимость от Chromium, фильтрация запросов в сетевом стеке, uBlock-фильтры почти без изменений |
| Визуальный язык | светлый минимализм: бумага, тонкие линии, серифные заголовки | не отвлекает от контента, читается как «инструмент», а не «портал» |
| Главная ценность | приватность и блокировка рекламы | защита по умолчанию, а не переключатель в настройках |
| Аккаунты | нет, всё локально | нет серверов → нет расходов и нет утечек |
| Монетизация | отложена | сначала продукт |

**Цена выбора GeckoView:** APK ~40–60 МБ, сложнее сборка (нужен Mozilla-репозиторий), меньше покрытие экзотических сайтов, чем у Blink. Для privacy-first продукта обмен оправдан; альтернатива — абстракция над движком, чтобы позже можно было вернуться к WebView.

## Экраны

1. **Старт** — приветствие, омнибокс с живым поиском (наберите `arch`, `gecko`, `wiki`, `eff`), быстрый доступ, «продолжить чтение», строка Nex Shield.
2. **Чтение** — статья с крупной серифной типографикой, режим «только текст», прогресс чтения под статус-баром.
3. **Вкладки** — сетка 2×N с превью, закрытие по крестику, «закрыть все», текущая вкладка обведена.
4. **Nex Shield** — кольцевая диаграмма, график по дням, четыре переключателя защиты (реклама, антитрекинг, cookie-баннеры, fingerprinting).
5. **Меню** — bottom sheet: инкогнито, история, закладки, настройки, «о браузере».

Горячие клавиши на десктопе: `1`–`4` переключают экраны, `Esc` закрывает меню.

## Как это ложится на Android

| Прототип | Реальный код |
|---|---|
| `.omnibox` + `.suggest` | `OmniboxView` + `SearchSuggestionProvider` |
| `#v-read`, режим чтения | `GeckoSession` + `ReaderModeController` (Readability-порт) |
| `#v-tabs` | `TabStore` (Room), `TabGridScreen` на Compose |
| `#v-shield` | `ContentBlockingController` (Gecko) + счётчики из `onBlockedRequest` |
| Инкогнито в меню | `GeckoSession.settings.usePrivateMode = true` |
| «Ссылка без трекер-параметров» | очистка query по списку `utm_*`, `fbclid`, `gclid` |
